### 🛡️ What I'm building

**[Sablewatch](https://sablewatch.com)** — an autonomous **Managed Detection & Response (MDR)** platform that monitors an organization's telemetry, surfaces threats, and drives response with a human in the loop.

- 🔎 **Detection on real telemetry** — analyzes connection and authentication events to flag suspicious activity
- 🏢 **Multi-tenant by design** — org-isolated data enforced with row-level security (RLS)
- 🤖 **AI-assisted triage** — automated investigation and response, human-in-the-loop for the decisions that matter
- 🎯 **Interactive Attack Range** — a live demo showing how detections fire against simulated attacker activity

### 🧭 Focus areas

`Detection & Response`  ·  `Cloud Security`  ·  `Application Security`  ·  `Security Automation & AI`  ·  `Multi-tenant SaaS`
